# Produto some do catálogo; o passado não se apaga

Desativar pausa o Produto: ele continua na lista como Desativado, sai do próximo Fechamento e o histórico antigo permanece.

Excluir tira do catálogo. Se nunca houve Fechamento, o Produto é apagado de verdade. Se houve, o passado fica no Histórico (nome e quantidades); o Produto não entra em Fechamentos futuros; o nome fica livre para cadastrar de novo.

Não se apaga o passado. A regra de negócio continua: todo Produto *ativo* entra no Fechamento.
