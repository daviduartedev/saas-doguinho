# Estoque é quantidade restante, não movimento

O operador informa a contagem física no encerramento; esse número substitui o Estoque da Loja. Entrada/saída/consumo ficam fora do MVP porque não há PDV nem compra no produto — o único fato que o operador consegue atestar é o que está na prateleira. Mudar para um modelo de movimentação depois exige reescrever Fechamento, histórico e invariantes.
